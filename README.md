# KrcPlayer (広告なし 高機能動画プレイヤー)

XPlayerの全機能を踏襲した、個人用・完全広告なしのAndroid動画プレイヤーアプリです。

## 主な機能

### 1. 動画管理・ブラウズ
- **フォルダ一覧 / 全動画一覧表示**: グリッドとリストでの快適なサムネイル・時間・サイズ表示
- **自動スキャン**: 端末内の動画を自動検出

### 2. 再生コントロール（XPlayer仕様）
- **ジェスチャー操作**:
  - 画面左側ドラッグ: 明るさ（輝度）調整
  - 画面右側ドラッグ: 音量調整
  - 画面横ドラッグ: 早送り / 巻き戻し（シーク）
- **倍速再生**: 0.5x 〜 3.0x 対応
- **アスペクト比切替**: フィット / ズーム全画面 / ストレッチ
- **画面回転・ロック**: 誤タップ防止ロック、縦横切り替え
- **ピクチャ・イン・ピクチャ (PiP)**: 小窓で別アプリを使いながら再生
- **バックグラウンド再生**: 音声のみ再生対応

### 3. シークレットフォルダ
- 4桁のPINコードで保護された秘密の保管庫
- 通常のギャラリーやファイル一覧から隠蔽

## インストール方法
1. GitHubの **Releases** ページを開きます。
2. 最新のリリースにある `app-debug.apk` をダウンロードします。
3. スマホ上でタップしてインストールします（提供元不明のアプリの許可を求められたら「許可」を選択）。
